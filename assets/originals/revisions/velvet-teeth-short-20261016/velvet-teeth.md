# Velvet Teeth

Короткая оригинальная фортепианная пьеса в ми миноре: **1:32.16** вместо прежних пяти минут. Ориентир — характер Wild Side из Beastars: быстрый шаффл, короткие синкопированные фразы, басовый пульс и ясная песенная форма. Мелодия написана заново; это самостоятельная композиция, а не транскрипция опенинга.

Примеры, предоставленные пользователем: [ThePandaTooth](https://www.youtube.com/watch?v=Ga0db-2eaxI), [Wild Side — piano](https://www.youtube.com/watch?v=Qo7wBm0W7fg), [Sheet Music Boss](https://www.youtube.com/watch?v=37sF3zS1x38). Страницы и визуальный формат примеров просмотрены в браузере; полного слухового сравнения с видео не проводилось.

В новой редакции основной мотив появляется после двух тактов вступления и узнаваемо возвращается в припеве. Вместо длинных сольных разделов — короткий куплет, подъём, припев и завершающая каденция. Мелодические ноты имеют разные длительности, аккорды могут удерживаться под следующими нотами. В басу и сопровождении сохраняется движение; быстрые пассажи не занимают целые разделы.

| Часть | Такты | Начало |
|---|---:|---:|
| Count-in riff | 1–2 | 0:00 |
| Night walk | 3–10 | 0:03.84 |
| Quickstep | 11–18 | 0:19.20 |
| Open the door | 19–26 | 0:34.56 |
| Dancing on the edge | 27–42 | 0:49.92 |
| Last turn | 43–48 | 1:20.64 |

Пресет: **Note Delay 80 ms / Key Hold Time 140 ms / Start Delay 3 s**. Темп — 125 BPM, размер — 4/4. Шесть клеток по 80 ms составляют четверть; свинговая пара — 320 + 160 ms, соотношение 2:1. 48 тактов по 1920 ms дают **92 160 ms**, без стартового отсчёта. Индивидуальные удержания записаны в sheet с помощью `<…>`; очеловечивание сохраняет их длительность. Предел одной атаки — семь физических клавиш.

Последняя доминанта разрешается в полное ми-минорное трезвучие с низким ми. Финальный аккорд удерживается 800 ms, затем затухает до окончания файла. Delay рассчитан из авторского темпа; базовое удержание служит запасным значением для нот без пометки. Звучание на браузерном пианино ещё не проверено. Для него используйте свободную игру и **Transpose 0**.

Файлы: `assets/songs/velvet-teeth.txt`, `assets/originals/velvet-teeth-score.json`, `assets/originals/velvet-teeth.mid`, `assets/originals/velvet-teeth.wav`. WAV — синтезированное фортепианное превью; MIDI и WAV используют один план с очеловечиванием и seed 20261016. Прежняя пятиминутная редакция сохранена в `assets/originals/revisions/velvet-teeth-five-minute-20261016`.

```powershell
python tools/compose_velvet_teeth.py
python tools/render_velvet_teeth.py --humanize --seed 20261016
```

Для рендера WAV нужен NumPy. Генераторы не изменяют пользовательский профиль. Если для этой песни ранее сохранены другие тайминги, кнопка **Пресет песни** применит новые 80/140/3.
