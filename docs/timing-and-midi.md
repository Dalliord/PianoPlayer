# Точный тайминг и MIDI

Существующие sheets и три основных параметра работают по прежним правилам. Новые команды заключаются в `|…|` и действуют на следующие ноты. Они не нажимают клавиши. Записанные в sheet команды имеют приоритет над базовым Note Delay.

| Команда | Значение |
|---|---|
| `\|bpm=120\|` | Темп: 120 четвертей в минуту. По умолчанию один шаг — шестнадцатая, 125 ms при 120 BPM. |
| `\|step=1/4\|` | Один шаг — четверть доли, то есть шестнадцатая. |
| `\|step=1/3\|` | Один шаг — треть доли: триоль. Допустимы дроби от 1/128 до 16 долей. |
| `\|ramp=180,8\|` | Плавный переход от текущего темпа к 180 BPM за 8 четвертных долей. Работает и для замедления. |
| `\|delay=75.5\|` | Точный интервал начала нот в ms, независимо от BPM. Допустимо 0–60000 ms. |
| `\|delay=0\|` | Ноты не продвигают время: интервалы можно задавать отдельно через wait. |
| `\|wait=250.5\|` | Дополнительная абсолютная пауза в ms. Она не продвигает музыкальные доли плавного перехода темпа. |
| `\|reset\|` | Вернуть базовый Note Delay, обычную шестнадцатую и отменить переход темпа. |

Например, мелодия начинается в 120 BPM, получает триольную фразу, затем ускоряется до 180 BPM:

```text
|bpm=120| |step=1/4|
[1<1200>tf] a s d
|step=1/3| f g h
|step=1/4| |ramp=180,8|
a s d f g h j k l z x c v b n m
|reset|
```

Плавный переход задаёт линейное изменение BPM по музыкальным долям. Время вычисляется интегрированием этой кривой, включая длинные паузы `-`, без приближённого накопления ошибок. `{…}` по-прежнему использует 35% текущего шага между нотами и обычный шаг после последней ноты.

Удержания допускают до трёх знаков после точки: `a<125.5>` или `[a<1000.25>s<200.125>]`. Диапазон остаётся 5–60000 ms. Удержания не прибавляются к интервалам. Верхняя граница длительности одного плана — 1 час. Временная точность плана не гарантирует такую же точность физических событий Windows и целевого пианино.

Справка с примерами доступна прямо под редактором: **«Обозначения и темп»**.

## Импорт MIDI

1. Нажмите **«Импорт MIDI»** вверху окна и выберите `.mid` или `.midi`.
2. Выберите дорожки. Дорожки без мелодических нот не импортируются; ударные канала 10 исключаются.
3. При необходимости выключите учёт педали sustain или адаптацию по октавам. При выключенной адаптации несовместимая партитура получает объяснение ошибки вместо скрытого изменения нот.
4. Проверьте сводку изменений и нажмите **«Добавить в библиотеку»**.

Поддерживаются синхронные SMF 0/1 с PPQN. Темп conductor-дорожки учитывается даже при импорте одной другой дорожки. Многочисленные смены темпа сохраняются как абсолютные времена с разрешением до 0.001 ms; нотная сетка Note Delay не округляет их. Удержания каждой ноты записываются отдельно. Отсчёт Start Delay остаётся отдельным.

Импорт использует `|delay=0|`, `|wait=…|` и `<…>`. Поэтому Note Delay и базовый Hold не растягивают готовую MIDI-партитуру: интервалы уже заданы в тексте явно. Для сохранения исходного исполнения без случайных отклонений выключите **«Очеловечивание»**. При включённой галочке применяются обычные небольшие вариации проигрывателя.

Педаль CC64 преобразуется в продление нот до её отпускания. Это приближение для виртуального пианино, а не настоящая фортепианная педаль. Также учитываются окончание ноты через `note_on` с нулевой velocity и команды all notes/sound off. Незакрытые ноты завершаются в конце файла и отмечаются в сводке.

Диапазон клавиатуры остаётся C2–C7. При включённой адаптации крайние ноты переносятся по октавам, а конфликтующие обычные и Shift-ноты перекладываются на свободные клавиши. Сохраняется класс высоты. Совпавшие унисоны объединяются с более долгим удержанием. При невозможности разместить все голоса сводка показывает число непоместившихся нот. Верхняя мелодия и нижний бас имеют приоритет. Повтор одной физической клавиши прерывает прежнее удержание; такие перекрытия тоже подсчитываются.

Velocity, тембры инструментов и громкость MIDI не передаются клавиатурой. Удержания короче 5 ms или длиннее 60 s ограничиваются этим диапазоном с отчётом. Формат 2 и SMPTE пока не поддерживаются. Пределы файла: 16 MB, 200000 мелодических нот, 500000 событий, длительность чуть меньше часа. Чтение и преобразование выполняются в фоне; отмена и ошибка не изменяют текущую песню.

Каждый импорт получает отдельный идентификатор и хранится одним JSON в `data/library`. Повторный импорт с тем же названием создаёт отдельную песню. Оригинальные файлы MIDI и встроенный каталог не изменяются. Пользовательские правки и тайминги сохраняются для импортированной песни так же, как для встроенных.

Формат MIDI читается библиотекой [Mido](https://mido.readthedocs.io/en/stable/files/midi.html). Структура SMF и карта темпа описаны в [спецификации MIDI Association](https://midi.org/standard-midi-files-specification). Импорт не открывает MIDI-порты и не отправляет файл в сеть.
