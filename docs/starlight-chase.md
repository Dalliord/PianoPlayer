# Starlight Chase

Оригинальная инструментальная пьеса для Piano Player. Мелодия, гармония и аранжировка записаны в `tools/compose_starlight_chase.py`; у пьесы нет страницы с проверочным sheet на сайте.

Энергичная мелодичная пьеса в ре миноре с подвижным басом и плотным аккордовым сопровождением. Форма: вступление 4 такта, тема 16, припев 16, контрастная часть 8, развитие 8, финальный припев 16, финальная тема 8, кода 4. Всего **80 тактов**, **2 минуты 40 секунд**, без стартового отсчёта. Сложность Hard — внутренняя оценка приложения.

Темп **120 BPM**, размер **4/4**, сетка — шестнадцатые. Четверть занимает 500 ms, одна клетка — **125 ms**, поэтому Note Delay рассчитан из авторского ритма. Key Hold Time **200 ms** выбран для этой фактуры и допускает перекрытие соседних шестнадцатых. Start Delay — **3 s**. Звучание на браузерном пианино ещё не проверено; удержание можно настроить вручную. Все три значения и правки sheet сохраняются отдельно для этой песни.

Используйте свободную игру на пианино со стандартной раскладкой PlayPianoSheets и **Transpose 0** (`1` = C2, `t` = C4, `p` = A4). Каждая непустая строка sheet содержит один такт из 16 клеток; `-` занимает одну клетку. Пробелы и пустые строки служат форматированием. Повтор той же физической клавиши прерывает предыдущее удержание, как и при обычной игре через клавиатуру.

Файлы:

- `assets/songs/starlight-chase.txt` — исполняемый sheet;
- `assets/originals/starlight-chase-score.json` — гармония, мелодия и сетка нот каждого такта;
- `assets/originals/starlight-chase.mid` — MIDI с темпом 120 BPM и инструментом General MIDI Acoustic Grand Piano;
- `assets/originals/starlight-chase.wav` — синтезированное превью с теми же началами нот и удержаниями, с коротким хвостом затухания. Тембр отличается от пианино сайта.

Пересоздать партитуру и превью:

```powershell
python tools/compose_starlight_chase.py
python tools/render_song.py --song starlight-chase --output-dir assets/originals
```

Для рендера WAV нужен NumPy; для работы приложения он не требуется. Экспорт использует исходный пресет без Start Delay и пользовательских правок. Генераторы не меняют пользовательские настройки.
