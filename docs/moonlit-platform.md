# Moonlit Platform

Оригинальная инструментальная пьеса для Piano Player. Ранее она называлась «Лунный перрон»; музыка, идентификатор и пресет сохранены. Мелодия и аранжировка записаны в `tools/compose_moonlit_platform.py`; музыка не импортирована с PlayPianoSheets.

Пьеса в ля миноре, с подвижным басом, синкопированной мелодией, септаккордами и нонаккордами. Форма: вступление 4 такта, тема A 8, вариация A 8, контрастная часть B 8, возвращение A 8, кода 4. В средней части появляются заимствованный Fm6 и отклонение через A7b9 в Dm. Всего 40 тактов, 350 звучащих событий, из них 285 аккордов. Сложность Hard — внутренняя оценка аранжировки приложения.

Темп **100 BPM**, размер **4/4**, сетка — шестнадцатые. Четверть длится 600 ms, поэтому Note Delay равен **150 ms**. Пауза `-` занимает одну клетку; каждая непустая строка sheet — ровно один такт (16 клеток). Key Hold Time **200 ms** задаёт короткую артикуляцию и допускает перекрытие соседних шестнадцатых. Start Delay **3 s** даёт время переключить окно. Продолжительность плана — **96 секунд**, без обратного отсчёта.

Настройка Delay рассчитана точно из авторского ритма. Hold выбран для этой фактуры, но звучание на инструменте сайта ещё не проверено. В приложении сохраняется возможность менять текст и все три значения отдельно для этой песни. Пианино должно использовать стандартную раскладку PlayPianoSheets с **Transpose 0** (`1` = C2, `t` = C4, `p` = A4). У пьесы нет готового проверочного sheet на сайте: используйте режим свободной игры.

Файлы:

- `assets/songs/moonlit-platform.txt` — исполняемый sheet;
- `assets/originals/moonlit-platform-score.json` — гармония, мелодия и сетка нот каждого такта;
- `assets/originals/moonlit-platform.mid` — MIDI с темпом 100 BPM и инструментом General MIDI Acoustic Grand Piano;
- `assets/originals/moonlit-platform.wav` — локально синтезированное превью с приближённым фортепианным тембром. Оно использует тот же план начал и удержаний, включая отпускание при повторе физической клавиши, с коротким хвостом затухания. Тембр отличается от пианино сайта.

Восстановить sheet и нотную сетку:

```powershell
python tools/compose_moonlit_platform.py
```

Пересоздать MIDI и WAV (требуется NumPy; для работы самого плеера он не нужен):

```powershell
python tools/render_song.py --song moonlit-platform --output-dir assets/originals
```

Генераторы не читают и не изменяют пользовательские настройки. Превью экспортирует исходный пресет композиции, без Start Delay и без пользовательских правок sheet.
